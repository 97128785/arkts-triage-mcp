# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-10-12

### Added

- Local stdio MCP server built with TypeScript and `@modelcontextprotocol/sdk`.
- `analyze_build_log`, `map_project_modules`, `trace_symbol`, and `explain_diagnostic`.
- Versioned diagnostic catalog for ArkTS, ArkUI, module, permission, and native loader failures.
- Ten anonymous fixture pairs and security-boundary tests.
- Credential redaction, log truncation, `realpath` workspace enforcement, and shell-free `rg`.
- Bilingual README, TraeCode MCP configuration, Agent Skill, architecture documentation, CI, and npm packaging.
